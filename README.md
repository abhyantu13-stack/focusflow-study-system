# 🧠 FocusFlow Study System

A focus-driven study web app designed to help students enter deep work, avoid distractions, and build consistent study momentum.

---

## 🎯 Problem

Students don’t struggle to plan —  
they struggle to **focus and complete tasks**.

---

## 💡 Solution

FocusFlow helps users:
- enter deep focus quickly  
- stay consistent  
- build study momentum  

---

## ✨ Features

- ⏱️ Focus Timer (Pomodoro)  
- 📋 Task Management  
- 🎮 XP & Streak System  
- 📊 Smart Dashboard  

---

## 🛠️ Tech Stack

- HTML  
- CSS  
- JavaScript  

---

## 🚀 Goal

To create a study tool students actually use.
